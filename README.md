# Chinese Flashcard

面向中文初学者的离线 Android 词卡应用。围绕「理解词语 → 写一写 → 四选一回忆 → 当日通过 → 到期复习」重新组织学习。参考不背单词的情境学习和简洁布局，界面与教学文案独立实现。

界面、答题选项和本义／引申义讲解使用英文，学习内容保留简体汉字和声调拼音。默认词库为 **9,223 个词条**，包含上一轮追加的 1,500 条词汇、成语和固定表达；当前按五个教育阶段全量重评罕度。成语选项展示现代通行义，多义项逐行以 ①②③ 区分。每词两条例句，按汉字分块、拼音分块、英语直译、自然英语整句四层呈现，删除使用提示。Profile 可追加导入新版 12 列 CSV，所需真实笔顺随 App 提供。当前使用 Room v7 数据库，旧版本个人设置、词库和学习记录不迁移；本次重评不修改数据库版本或已有学习记录。

## 使用链路

- **Welcome**：名字／头像、每日词量、复习日期三个居中页面。每天新词默认 10，可选 5–50、每档 5 个；复习日期可从 1 / 3 / 5 / 7 / 14 / 30 天中多选。Profile 可修改连续正确轮次，默认 4，可选 2–8。
- **Today**：新学、到期复习、跨天未完成任务分别显示进度；Words today 下方显示 `stage {罕度} {英文阶段名称}`、该档进度条和该档已学／总词数。按最低尚未学完的非空档确定当前阶段，沿用词条的首次通过记录，学完自动进到下一档；全部通过时显示最后一个非空档的完成状态。可恢复词卡与写字草稿，显示词库总量、已通过和未开始数量。
- **Study**：一个词、四个英文释义选项。每组最多五词交错学习，前两轮显示不同的中文例句、拼音和英文翻译，后续隐藏例句。答对显示中文并朗读，朗读完成后自动进入解析；语音失败时可点 Next。答错或选择不知道，当前词的连续正确轮次归零，反馈朗读后仍由 Next 进入解析。
- **Explanation**：英文义项、四层例句和词语部件，进入后再自动朗读一次词语。拆解作为记忆线索，不把词语联想当成字源。
- **Review**：到期词先做一次无例句回忆；答对完成本次复习，答错进入完整重学。重学通过后重新安排复习。
- **Profile**：修改学习设置、查看学习量、Import CSV 预览并确认追加词库、打开来源与许可。
- **Wordlist**：查看已导入词库的整体进度，按 All / Unlearned / Learning / Learned 和 Stage 0 / 1 / 2 / 3 / 4 筛选，搜索汉字、拼音或英文释义。点击词条可听音、查看讲解或手动书写，返回列表时保留筛选和位置。

当日目标和已有学习周期的设置固定；修改日词量用于下一份日计划，新学习／重学周期采用最新轮次和复习日期。第 N 天指通过日之后的 N 个日历日。错过多次到期节点的同一词，当天只出现一次复习；未完成的学习跨天轮次归零，以独立任务继续，不占新词额度。

下一份新词计划、跨天续学、Learn more 和词表浏览先按罕度升序，再按每个拼音音节的字母、声调、下一音节排序；声调为一二三四声、轻声，ü 紧随 u，完全同音同调按 ID 稳定排列。当天已有计划和当前卡片保持原序，到期复习按到期顺序。罕度为 0 小学一年级（Primary school）、1 初中一年级（Middle school）、2 高中一年级（High school）、3 大学一年级（University）、4 汉语言专业一年级（Specialist）。按当前主义项、语境和教育背景作逐词 AI 评估，不设配额，也不声称官方逐年级教材词表认证。CSV 仅重写罕度列，原 9,223 条的其余字段、ID 和物理顺序保持；学习排序不重排表本身。分布与覆盖记录见 `docs/wordlist-validation.json`。

底部导航为 Home / Profile / Wordlist。词库中的 Learned 表示曾完成学习轮次，复习答错不会减少累计已学数；Learning 表示已进入首次学习但尚未通过。浏览讲解和书写都不会增加学习轮次或标记掌握。日词量选择使用 5–50 的五词档位。

## 写一写

首次遇词在讲解后自动进入写字；复习错误的讲解后也自动进入一次写字，可选择稍后再写。同一重学周期重复出错不会重复自动打开。

使用田字格和真实笔画轮廓／中线，保留笔顺动画、暂停、逐笔示范、重播、描红／临写、撤销、重试与轨迹反馈。词语和拼音在画布上方，当前字标红；英文解释列按最长完整单词实测宽度扩展，按空格折行，并保留横向滚动。最后一笔接受后自动推进到下一个字／词，全部完成后显示 Done。

每个字形独立存储在 Room 的 `tracing_items`，`word_tracing` 按词语与字符位置关联。重复字如「谢谢」共享同一份字形数据，但两个位置分别练习。写字草稿和完成记录独立保存，不增加词卡轮次，也不等同于词汇掌握。

当日所有新学／复习／续学任务完成后，若有今日首次通过的新词，显示一次柔性邀请：「是否去写一写今天新学的词汇？」可以开始、拒绝或关闭。完整词语写字包含之前自动练过的字。

## 词库、演示数据与来源

[CSV 格式与导入说明](docs/CSV_IMPORT.md) 记录新版 12 列、限制、追加与取消语义。根目录 `wordlist.csv` 是打包权威产物，重构前最终词表冻结于 `tools/wordlist_rebuild/baseline.csv`，语块、英文解释、75 条新成语和一次性 ID 映射同目录保存。使用 `python tools/rebuild_wordlist.py --apply` 可复现最终 CSV；ID 映射冻结后不自动重新编号。旧生成／分级入口在新版词表下拒绝覆盖。Room v7 使用 `chinese-flashcard-v2.db`，直接归属标记、教学内容、排序及 SHA-256 版本一起事务提交；无旧库迁移与历史指纹认领。

首次启动、默认库重试和手动导入共用居中加载组件：进度条加百分比共占可用内容宽度的 75%。百分比跟随整体加权进度，提交前最多 99%，成功后为 100%；预览的 100% 表示校验就绪。进度最多每 100 ms 刷新，笔顺最多两个分包并发解码，数据库事务内串行写入。

词库释义采用 [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cc-cedict) 与固定版 [mapull/chinese-dictionary](https://github.com/mapull/chinese-dictionary) 参考，保留 CC BY-SA 4.0 与上游 MIT 许可。新成语每条有两句原创现代例句；旧词全量补充释义与拆分，具体编辑和机器辅助内容的覆盖边界见 [内容与验证记录](docs/WORDLIST_REFINEMENT.md)。笔顺沿用 Make Me a Hanzi，并采用 [AnimCJK 简体中文固定版本](https://github.com/parsimonhi/animCJK/tree/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6) 补充其缺字。完整来源、版本、修改说明、资源哈希和许可位于 `core/data/src/main/assets/wordlist-strokes/`，可在 App 的 Data & licenses 查看。

20 个演示词仅供书写展示补充，不初始化到新词库；其 40 个例句也使用新版语块契约。只读检查：

```powershell
python tools/build_demo.py --check
```

`--check` 校验当前手写演示契约、语块和字形关联。旧模板生成操作已停用，避免覆盖新版内容。全表检查使用 `python tools/rebuild_wordlist.py --check`。

笔顺来自 [Make Me a Hanzi](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92)，固定提交 `bddc96d41bef78427ed0e034e9f7e31d71fd1b92`。保留原始轮廓、中线、Arphic Public License 与 COPYING；不分发其 dictionary 数据。完整许可可在应用中查看。

仅调用系统报告为已安装、无需联网的普通话 TTS。缺少语音或引擎失败时提示并允许继续学习；没有账号、联网权限、录音或上传。
