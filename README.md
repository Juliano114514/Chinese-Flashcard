# Chinese Flashcard

面向中文初学者的离线 Android 词卡应用。围绕理解词语、写字、四选一回忆和到期复习组织学习。界面支持英文／中文，学习内容保留简体汉字、声调拼音及英文释义。可按现有双语词条学习中文或英文，默认英文界面学中文。

当前源码版本 **1.8.0**，默认词库 **18,500 条**，每词两条例句。恢复 Stage 0–4（小学、初中、高中、大学、专业）及原五套主题，每阶段有浅色／深色配色；页面沿用统一阅读底色。

当前源码合并原罕度0/1，其余依次减一，保留扩充词库并修订单字、组词及拆解；配色恢复绿、蓝、紫、玫红、橙。单字由3,272减为1,148，修订依据见[五档与词库精修](docs/WORDLIST_REFINEMENT_20261027.md)。最新源码调整尚未重新打包；此前已安装的1.6.9属于六档快照，历史验证见[罕度重分记录](docs/RARITY_REBALANCE_20261027.md)。

## 学习与使用

- **Welcome / Profile / Settings**：Profile 展示昵称、头像、统计及 QQ 等级，右上角齿轮进入 Settings。每日新词、连续正确轮次、复习日期、CSV 导入和许可入口集中在 Settings；主题可选浅色、深色或跟随系统，继续使用当前阶段配色。默认每日 10 词、连续正确 4 次；日词量可选 5–50，轮次 2–8，日期从 1 / 3 / 5 / 7 / 14 / 30 天中多选。
- **等级成长**：每天首次打开 +1 天，完成当天 Learn +1 天；新学／续学或收藏练习每完成 10 个词条 +1 天，每累计消除 20 个待处理错词 +1 天，余数跨天保留。默认从 1 级开始；达到等级 `n` 需累计 `(n−1)² + 4(n−1)` 天；4 星换 1 月，4 月换 1 日，4 日换 1 冠。启用后开始累计，不补记历史；普通复习答对、浏览、收藏操作和写字不计学习完成次数。
- **Home**：Study 显示 today、review、words 三条进度。today 按当前学习语言累计当天完整完成的新学和续学词，跨标签与 Stage 去重；达到当天冻结的每日目标即完成，可主动 Learn more，每批最多五词，复习独立进行。words 为当前 Stage＋筛选范围内曾学会的词量。Study 右侧入口进入标签页，默认全页单选，可切换多选；多选时同组任选、不同组同时满足，Topics 首项 In total 清除所有条件。标签显示已学／总数，全部学会后增加绿色描边，开启新一轮或复习错误不取消完成状态。切换标签或 Stage 会重新组建当前范围的新学／续学列表，再恢复逐词轮次并预加载；其他范围的进度保留。词汇区域底部左侧 Replay 重播当前词，右侧 Shuffle 换词并显示 ready 数量；两者沿用首页朗读设置，不读例句。复习、收藏和错词练习保持各自计划。
- **Study**：每组最多五词交错练习；上方显示所学语言的生词，下方选择熟悉语言的释义。学中文使用中文词头／拼音和英文选项（选项不带音标），学英文使用逐行英文义项和中文／拼音选项。前两轮显示所学语言的例句，后续隐藏；提交后恢复双语反馈和讲解。答对朗读后进入解析；答错／不知道使连续正确轮次归零。
- **Review**：无例句回忆一次答对即完成本次复习；错误进入重学，通过后重新安排复习。同词多个逾期节点当天折叠为一次。当天复习完成后，首页 Review 的副标题显示 Review {N} more，完成页可点击 Continue review，随机抽取当前学习语言的已学词汇继续复习；默认每批 10 词，Settings 可设为 1–50。排除已 skip 和正在重学的词，不足一批时使用全部可用词；每批内不重复，批次之间可重复。
- **Wordlist**：标题右侧按全库标签筛选，与下方难度、状态、搜索和收藏组合；重置图标清除全部浏览条件并回到顶部。搜索和筛选词库，收藏、skip／取消 skip、听音、讲解与手动写字。浏览和书写不增加学习轮次，Learned 表示曾完成首次学习，复习错误不减少累计数量。
- **Writing**：田字格、真实笔顺轮廓／中线、动画、逐笔示范、描红／临写、撤销和轨迹反馈。在意思与写字区之间显示笔画中文名及英文提示，演示或正确书写后播放内置名称音频，可点击重听；书写页不再朗读词汇。少量缺失／不确定笔画名称暂缺。逐字符保存草稿，写字完成不等于词汇掌握；首次遇词及复习错误可自动进入，也可跳过。
- **Import CSV**：在 Settings 选择新版 12 列 CSV，预览后确认追加；默认库与自定义内容保留独立归属。支持的结构和限额见导入文档。
- **进度码**：Settings 的 Data 分组支持复制导出、粘贴预览并确认合并。仅包含中文学习状态、skip 和中文错词；未学且无标记的词省略；各状态自动选择区间、差值列表或位图的最短编码，带完整性校验，只接受新版 CFP3 码。已学状态不会退回，标记按并集合并，缺失 ID 跳过并提示。导入的已学词按复习已完成恢复，不补排复习，仍可主动继续复习；本机已有会话及复习安排保留。不迁移收藏、英文进度、答题轮次、词库内容、设置、等级或历史每日记录。

首页右侧语言入口打开独立弹窗，一并选择“系统语言／学习语言”；Settings 也保留两项独立设置。中文与英文方向的学习、复习、错词、skip、每日计划及阶段进度独立；收藏书签、头像和成长等级共用。旧记录全部保留在学中文方向。切换方向会暂停原会话，切回来可继续；学英文的学习页不展示写字或进入描红，词库详情仍可手动写中文。

界面文案统一使用 Android XML 字符串资源：`core/ui/src/main/res/values/strings.xml` 为英文默认值，`values-zh/strings.xml` 为对应中文，Compose 按同一资源 ID 读取。界面语言切换保持字体大小及当前主题，不翻译或修改词库内容。

英文主释义按分号分行，各行可听音；命中开放美式词典的单词显示 IPA，短语或缺失条目不伪造音标。双语例句可分别朗读，答题前隐藏对照答案。英语语音使用 ONNX Runtime + 内置 Kitten Nano INT8，发音数据覆盖当前冻结词库，无需联网。未覆盖的用户导入文本使用设备已安装的离线英语 TTS；语音不可用时可继续学习。资源与许可见 [英语语音维护](docs/ENGLISH_SPEECH.md)。

中文朗读内置 MeloTTS FP32，保留当前声线；单字统一使用上下文生成、模型时长截取及弱音重试，优先采用 23 个已核听问题读法的固定样音。短词进行有界电平校正，长句沿用首尾边界与 0.7 倍模型语速；词语、例句及写字听音使用各自拼音。中文资源约 186 MB，首次使用无需联网下载；未覆盖或无法可靠转换的读音、模型故障和不合格输出回退到已安装的离线普通话。试听、资源准备及手机验证边界见 [中文语音维护](docs/MELO_TTS_EVALUATION.md)。

修改设置不重算当天计划或已开始的学习周期。复习间隔按通过日后的日历日计算；跨天未完成任务轮次归零，作为续学保留，不占新词额度。同罕度的新词按拼音音节字母、声调及稳定 ID 排序，现有计划保持原序。

## 工程

| 模块 | 职责 |
| --- | --- |
| app | 启动、导航、依赖装配和许可入口 |
| core/domain | 纯 Kotlin 模型、Repository 契约与轨迹匹配 |
| core/data | Room、CSV 与默认库、笔顺资源、事务化学习与写字状态 |
| core/ui | Compose 组件、阶段主题和统一文案 |
| core/media | 内置 Melo 中文／Kitten 英语语音、离线系统回退与音频焦点 |
| feature/study | 欢迎、今日、词卡、讲解、完成页及学习反馈音效 |
| feature/writing | 独立写字流程 |
| feature/profile | 设置、统计与导入 |
| feature/wordlist | 词库浏览、详情与手动书写入口 |

保留上述九个运行时模块。独立的 `build-logic` 工程提供 Android application、library 和 Compose 约定插件，共享 compileSdk、minSdk、Java 字节码目标及 Compose 开关；依赖版本集中在版本目录，各模块仍声明自己的依赖与特殊构建任务。`core/domain` 的 `StudySettingsRules` 统一产品设置范围；历史每日词量的兼容校验与新设置选项保持区分。Study 通过契约调用语音，不直接依赖媒体实现模块。

使用 Kotlin、Jetpack Compose、Repository／Flow、MVI 与轻量 MVVM。applicationId 为 `com.example.chinese_flashcard`，Room schema v18（迁移实现已更新，schema导出待下次KSP构建）。应用使用本地数据库和内置离线语音，生成音频采用可调容量的持久 LRU 缓存；统一协调器在首页空闲时预热各学习入口的首词词音，学习时先准备当前词及后续词的词音（后续默认 5 词），再补齐例句。首页 Shuffle 使用独立候选队列，只预热词音，切换页面时保留候选；当前主 Manifest 未声明联网或录音权限，隐私边界见下方说明。
