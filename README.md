# Chinese Flashcard

面向中文初学者的离线 Android 词卡应用。围绕理解词语、写字、四选一回忆和到期复习组织学习。界面与讲解使用英文，学习内容保留简体汉字和声调拼音。

当前版本 **1.3.0**，默认词库 **13,223 条**，每词两条例句。使用五个教育阶段标注学习罕度；每阶段有浅色／深色主题，共十套强调色配色，页面采用统一的浅色／深色阅读底色。

## 学习与使用

- **Welcome / Profile / Settings**：Profile 展示昵称、头像、统计及 QQ 等级，右上角齿轮进入 Settings。每日新词、连续正确轮次、复习日期、CSV 导入和许可入口集中在 Settings；主题可选浅色、深色或跟随系统，继续使用当前阶段配色。默认每日 10 词、连续正确 4 次；日词量可选 5–50，轮次 2–8，日期从 1 / 3 / 5 / 7 / 14 / 30 天中多选。
- **等级成长**：每天首次打开 +1 天，完成当天 Learn +1 天；新学／续学或收藏练习每完成 10 个词条 +1 天，每累计消除 20 个待处理错词 +1 天，余数跨天保留。默认从 1 级开始；达到等级 `n` 需累计 `(n−1)² + 4(n−1)` 天；4 星换 1 月，4 月换 1 日，4 日换 1 冠。启用后开始累计，不补记历史；普通复习答对、浏览、收藏操作和写字不计学习完成次数。
- **Home**：显示新学、到期复习和跨天续学进度；stage 0–4 限制新学选词。复习和续学沿用自身计划，收藏／错词练习使用独立会话。
- **Study**：每组最多五词交错练习，四个英文选项；前两轮显示不同例句，后续隐藏。例句依次显示分块汉字、拼音、英文直译及整句自然英文。答对朗读后进入解析；答错／不知道使连续正确轮次归零。
- **Review**：无例句回忆一次答对即完成本次复习；错误进入重学，通过后重新安排复习。同词多个逾期节点当天折叠为一次。
- **Wordlist**：搜索和筛选词库，收藏、skip／取消 skip、听音、讲解与手动写字。浏览和书写不增加学习轮次，Learned 表示曾完成首次学习，复习错误不减少累计数量。
- **Writing**：田字格、真实笔顺轮廓／中线、动画、逐笔示范、描红／临写、撤销和轨迹反馈。逐字符保存草稿，写字完成不等于词汇掌握；首次遇词及复习错误可自动进入，也可跳过。
- **Import CSV**：在 Settings 选择新版 12 列 CSV，预览后确认追加；默认库与自定义内容保留独立归属。支持的结构和限额见导入文档。

修改设置不重算当天计划或已开始的学习周期。复习间隔按通过日后的日历日计算；跨天未完成任务轮次归零，作为续学保留，不占新词额度。同罕度的新词按拼音音节字母、声调及稳定 ID 排序，现有计划保持原序。

## 工程

| 模块 | 职责 |
| --- | --- |
| app | 启动、导航、依赖装配和许可入口 |
| core/domain | 纯 Kotlin 模型、Repository 契约与轨迹匹配 |
| core/data | Room、CSV 与默认库、笔顺资源、事务化学习与写字状态 |
| core/ui | Compose 组件、阶段主题和统一文案 |
| core/media | 系统离线普通话 TTS 与音频焦点 |
| feature/study | 欢迎、今日、词卡、讲解和完成页 |
| feature/writing | 独立写字流程 |
| feature/profile | 设置、统计与导入 |
| feature/wordlist | 词库浏览、详情与手动书写入口 |

使用 Kotlin、Jetpack Compose、Repository／Flow、MVI 与轻量 MVVM。applicationId 为 `com.example.chinese_flashcard`，Room schema v9。应用使用本地数据库和已安装的离线普通话 TTS，当前主 Manifest 未声明联网或录音权限；隐私边界见下方说明。
