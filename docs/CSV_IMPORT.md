# 词库 CSV 与直接导入

根目录 `wordlist.csv` 是打包默认词库的来源。构建任务生成 `default-wordlist/wordlist.csv`、SHA-256 `version.txt` 和记录总量 `rows.txt`，首次启动在后台完整校验并入库。当前词库共 **9,223 条**：上一轮在 7,723 条后追加 1,500 条，新 ID 为 `wl_07724` 至 `wl_09223`。本轮按五个教育阶段重评全部罕度，CSV 只改罕度列，其余 11 列和物理顺序保持。原一次性编号映射、追加数据及本次分级分别冻结在 `tools/wordlist_rebuild/id-map.json`、`expansion-20261005.json`、`stage-grading-20261005.json`；重建依次复现三部分，不再重新编号。

12 列重构阶段采用 **Room v7** 和新数据库 `chinese-flashcard-v2.db`，与更早的旧本地库不兼容：旧学习记录、复习与写字状态、设置和自导入词库全部重新开始。旧版本迁移、历史内容指纹认领和旧读音纠错登记已移除；运行时加载错误不会触发额外的清库或降级。后续 1,500 条追加和本次五档重评均不修改数据库版本，也不清空已有 v2 学习记录。

默认库内容、罕度、学习排序和成功版本标记在同一个事务中提交。新库初始化失败显示 Retry；已有新库的预设更新失败保留当前库可用，Profile 提供独立 Retry。默认库版本匹配时不重复处理；当前进程不会自动反复重试失败的更新。

在 **Profile → Import CSV** 选择文件。App 先显示总行数、新增词数、重复词数和错误；无错误且有新增词时，点击 Import 确认。关闭预览或取消读取不会写入词库，确认写入期间禁用对话框关闭。导入词语复用讲解、四选一、复习和逐字写字链路。

## 文件格式与教学字段

使用严格 UTF-8，可带 BOM。支持逗号分隔、CRLF/LF、引号内逗号和换行、双引号转义。包含逗号、引号或换行的字段必须包在双引号中，字段内部的 `"` 写成 `""`；不自动识别分号或制表符分隔。

当前格式恰好包含以下 **12 列**。按表头名称定位，可以调整列顺序；表头须唯一，不接受额外列或旧格式。全部 CSV 字段均须非空；没有独立引申义时使用 JSON 数组 `[]`。

| 列 | 内容 |
| --- | --- |
| 罕度 | 0、1、2、3 或 4；对应小学一年级、初中一年级、高中一年级、大学一年级、汉语言专业一年级，越小越优先学习 |
| 组词 | 1–32 个汉字，简体教学词语；包括需单独学习的单字 |
| 拼音 | 已校订的普通话读音，每个汉字的音节用空格或隔音符分开；轻声不标调 |
| 词条ID | 1–92 位 ASCII 字母、数字或下划线，唯一且用于引用 |
| 英文释义 | 四选一答题使用的一个主义项，最多 300 字符 |
| 词性 | 该主义项的英文词性，最多 80 字符 |
| 例句JSON | 恰好两条不同例句；每条有 `hanzi`、`pinyin`、`english`、`chunks` |
| 部件JSON | 有序数组；每项恰好有字符串 `hanzi`、`pinyin`、`gloss`，拼接汉字必须还原词语 |
| 干扰词ID | 恰好三个不同词条 ID 的 JSON 字符串数组，不含本词；引用本 CSV 或已保存词条 |
| 来源说明 | 释义、例句与修改依据；留在 CSV 中，不加入教学数据库 |
| 本义解释JSON | 非空英文字符串数组，按独立义项保存；不编造词源 |
| 引申义解释JSON | 英文字符串数组，没有独立延伸义时为 `[]` |

`使用提示` 已从 CSV、领域模型、数据库和讲解界面完整删除。两种解释数组只保存英文，不在数据中预先写入序号；界面在多义项时展示 **① ② ③**，单一义项直接展示。成语答题短义和长讲解分别使用，字面形象或典故不作为正确选项的唯一线索。

每条例句依次展示四行：分块汉字、分块拼音、对应英文直译，以及下方整句自然英文译文；前三行各块用 ` / ` 分隔。`chunks` 是非空有序数组，每块恰好包含字符串 `hanzi`、`pinyin`、`gloss`；直译可以明确标注 `LE`、`DE` 等语法标记。分块汉字原样拼接须重建整句，包含标点；分块拼音拼接后经过 NFC、大小写及空白／隔音符规范化，须与整句拼音一致。标点附在相应分块内，不创建只有标点和空拼音的块。例句必须包含完整词语，英文直译与自然译文均需作者核实。例句中的完整词拼音可按明确的词界连写，如 `sīkǎo`；主词拼音仍保留逐汉字音节分隔，供学习排序与整词校验使用。

例句字段示例（以下为 JSON 内容，写入 CSV 时还需按 CSV 规则转义双引号）：

```json
[
  {
    "hanzi": "我八点起床了。",
    "pinyin": "wǒ bā diǎn qǐ chuáng le.",
    "english": "I got up at eight o'clock.",
    "chunks": [
      {"hanzi": "我", "pinyin": "wǒ", "gloss": "I"},
      {"hanzi": "八点", "pinyin": "bā diǎn", "gloss": "eight o'clock"},
      {"hanzi": "起床了。", "pinyin": "qǐ chuáng le.", "gloss": "get up + LE (completed action)"}
    ]
  },
  {
    "hanzi": "他每天早上起床。",
    "pinyin": "tā měi tiān zǎo shàng qǐ chuáng.",
    "english": "He gets up every morning.",
    "chunks": [
      {"hanzi": "他", "pinyin": "tā", "gloss": "he"},
      {"hanzi": "每天", "pinyin": "měi tiān", "gloss": "every day"},
      {"hanzi": "早上", "pinyin": "zǎo shàng", "gloss": "morning"},
      {"hanzi": "起床。", "pinyin": "qǐ chuáng.", "gloss": "get up"}
    ]
  }
]
```

部件示例：`[{"hanzi":"学","pinyin":"xué","gloss":"learn"},{"hanzi":"习","pinyin":"xí","gloss":"practice"}]`。姓名、音译和不能可靠拆释的词可用整个词作为一个部件；部件讲解是记忆辅助，不能当作字源证明。解释示例：`["Learn knowledge or a skill.","Learn from another person."]`。

词语与部件拼音仅使用拼音字母、声调字母、空白及音节分隔符；例句和分块拼音还可使用常见中英文标点。支持 `ng`、`hng` 等鼻音，轻声不标调，不接受数字声调、中文或纯标点拼音。JSON 使用上述明确形状，不接受注释、裸字符串、尾逗号、错误类型或超过四层的嵌套。英文解释、分块直译和整句译文须含英文字母且不含汉字；字符与结构检查不能证明实际词义或读音正确。

## 限额、追加与事务

- 文件最多 **32 MiB**，每条原始 CSV 记录最多 **32 KiB**。底层解析器最多读取 64 列，当前教学契约要求恰好 12 列。
- 单次最多 **10,000 条**，追加后的整个词库也最多 **10,000 条**。
- 词语最多 32 个汉字、64 个 UTF-16 字符；词条拼音最多 128 字符。例句汉字最多 1,000 字符，拼音和自然英文译文各最多 2,000 字符。
- `例句JSON` 最多 16,000 字符，恰好两句，每句 1–64 块；每块汉字最多 1,000 字符，拼音和英文直译各最多 2,000 字符。
- `部件JSON` 最多 16,000 字符及 32 项；每项汉字、拼音、gloss 分别最多 64、128、300 字符。
- 两种解释 JSON 各最多 16,000 字符及 16 个义项，每项最多 2,000 字符；来源最多 2,000 字符，干扰词 JSON 最多 400 字符。各字段同时受整条 32 KiB 记录上限约束。
- 错误显示原文件物理行号和字段，最多显示前 100 项，同时保留错误总数；多行记录的内容错误定位到起始行，语法错误定位到发生错误的行。全部内容、引用、四个选项的区分和所需笔顺均通过校验后才能确认整批导入。

手动导入仅追加。相同 ID 的相同词，或相同「汉字＋规范化读音」的词跳过；读音规范化使用 NFC，忽略大小写、空格和隔音符／连字符，保留声调。同 ID 对应不同词语或读音时整批拒绝。CSV 内 ID 必须唯一，不同 ID 指向同词同读音时保留第一条，并映射后续引用。手动重复导入不覆盖已有释义、学习进度、复习节点或写字记录。

预设 SHA-256 版本变化时，仅通过已有 `presetSourceId` 直接刷新受管词的教学内容与罕度，不再用旧内容指纹认领。手动导入不设置归属；自定义内容不会仅凭同字同读音被改写。受管 ID 不得重新分配给不同汉字，同一词的读音可随经过校订的预设更新。更新前检查未完成卡片的四个 meaning ID 和更新后的短义；冲突时整批回滚，完成旧卡后 Retry，不重判已提交答案。

选择的 URI 仅在应用层使用，内容复制到 App 私有缓存中的随机临时快照。预览和确认读取同一快照；取消、完成、读取失败和下次启动清理遗留快照，不持久保存 URI，不新增存储、账号或联网权限。确认时在既有串行锁内重新校验，在同一个 Room 事务中写入笔顺、词语、义项、逐字关联和学习排序。失败或提交前取消回滚整批；提交完成后的取消不能撤销已提交事务。

## 学习排序与加载进度

学习顺序按罕度升序，然后**逐音节**比较该音节的无调字母、声调，再比较下一音节。`ü` 独立且紧随 `u`，同字母声调顺序为 1、2、3、4、轻声 5；公共音节前缀相同时短词先，同音同调以词条 ID 稳定兜底。使用词条已录拼音，不按汉字自动猜读音。每次追加或预设更新的事务内重算全库 `sortOrder`，词表、新词、Learn more 和跨天续学共用该顺序；当天已冻结的计划与当前卡片保留原序，到期复习继续按到期顺序。

罕度为五个教育阶段：0 小学一年级（Primary school）、1 初中一年级（Middle school）、2 高中一年级（High school）、3 大学一年级（University）、4 汉语言专业一年级（Specialist）。本次逐词重评全部 9,223 条，以当前主义项、语境、抽象程度及专业背景为依据，不用词频、字数或旧罕度直接套档，不设等量配额。罕见理工、医学和法律词归一般大学档；语言文学专门概念及需要相应阅读背景的古典表达才进入专业档。统计和覆盖见 `wordlist-validation.json` 与 `tools/wordlist_stages_20261005/`；此为实用学习阶段估计，不是官方逐年级教材词表认证。

`来源说明` 中上一轮的分档文字保留为历史生成记录；当前档位以罕度列及新的分级覆盖层为准，不为本次重评改写其他教学字段。

主页 Words today 下方显示 `stage {当前罕度} {英文阶段名称}`。根据词条现有的首次通过记录，选取最低尚未学完的非空档，进度条和数字仅计算该档的已学／总量；空档跳过，全部通过后保留最后一个非空档的完成状态。重分级不会清空学习记录，也不会把复习答错的词重新计为未学。

首次加载、默认库重试和手动 CSV 读取／确认写入共用居中的进度组件。**进度条、间隔和百分比的总宽度为父容器的 75%**，阶段信息居中；百分比按整体进度向下取整。内部记录数按 CSV 逻辑记录计数，重复词也计入扫描量，计数不代表已提交的新增数。

实际加载的整体进度连续递增：校验占 20%，笔顺占 65%，保存占 14%；COMMITTING 显示至多 99%，事务成功后 COMPLETE 才显示 100%。CSV 预览使用校验 20%／笔顺 80%，其 COMPLETE／100% 仅表示预览就绪，尚未写入数据库；确认或重试开启新的进度，错误不冒充成功。

进度由加载协程汇总，通常最多每 100 ms 发布一次，首条、阶段切换和完成立即发布。仅进度组件订阅该 Flow。笔顺索引和验证结果在进程内缓存，最多两个分包并发解码；数据库写入在事务所属协程串行执行，取消与失败保留回滚语义。

## 笔顺、来源与验证边界

CSV 不内嵌笔顺，不在运行时下载笔顺。每个字符位置必须能在随 App 分发的 `wordlist-strokes/index.json` 中找到真实轮廓和中线；重复字共享资源但逐个位置练习。本次 1,500 条新增词复用既有 **6,324 字**资源包，无需新增笔顺。资源之外的字会在导入预览报错，需要先补充并验证真实资源。每包最多 128 字且不超过 1 MiB，资源来源、固定版本、SHA-256 和完整许可随 assets 保存，Data & licenses 提供入口。

原始文件保存在 `wordlist.original.csv`，早期删除依据保存在 `wordlist-removals.csv` 和 `wordlist-placeholder-audit.json`。本次冻结基线、例句、解释、追加成语、一次性 ID 映射和审校覆盖分别保存在 `tools/wordlist_rebuild/`；旧生成器的生产快照不用于覆盖新格式。当前入口为 `tools/rebuild_wordlist.py`：`--prepare` 生成草稿，`--apply` 写入，**`python tools/rebuild_wordlist.py --check` 只读核对最终结构、引用、内容形状、资源覆盖及冻结清单一致性**。
