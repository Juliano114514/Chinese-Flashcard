# 词库 CSV 与直接导入

根目录 `wordlist.csv` 是打包预设字库的来源。构建任务生成 `default-wordlist/wordlist.csv`、SHA-256 `version.txt` 和记录总量 `rows.txt` assets，首次启动在后台校验并入库；不需要在 Profile 手动选择该文件。新装初始化 CSV 的 7,648 词，包括追加的 1,000 条成语；仅有旧 20 个演示词的安装升级后为 7,653 词。根目录 `wordlist.csv` 是最终校订的权威产物。作者记录、冻结选表和旧分级映射保存最后直接校订前的生产快照；运行旧生成器或 `--apply` 会覆盖最终校订，不能据此重建当前 CSV。

默认库的归属认领、受管词教学内容刷新、缺词追加、罕度更新和成功版本标记在同一个事务中完成，包括零新增的情况。新装失败显示 Retry；升级失败保留已有词库可用，在 Profile 显示错误和独立 Retry。当前进程不会自动反复重试失败的默认加载。重试仍执行完整校验；不覆盖未认领的自定义教学内容，也不重排已有日计划。

在 **Profile → Import CSV** 选择文件。App 会先显示总行数、新增词数、重复词数和错误；无错误且有新增词时，点击 Import 确认。关闭预览或取消读取不会写入词库。确认写入期间禁用对话框关闭，避免误操作。

导入的词语复用现有讲解、四选一、复习、逐字完整写字链路。成功后刷新统计；当天已生成的计划保留，新词从下一份日计划参与选词。新词、跨天续学与 Learn more 按罕度、保存的顺序、稳定 ID 排序；到期复习继续按到期顺序。罕度为 0/1/2/3，表示具体的学习期望，**不是 HSK 等级**。

## 文件格式

使用严格 UTF-8，可带 BOM。支持逗号分隔、CRLF/LF、引号内逗号和换行、双引号转义。包含逗号、引号或换行的字段必须包在双引号中；字段内部的 `"` 写成 `""`。不把分号或制表符自动当作分隔符。

交付 CSV 保留原十六列，并在末尾增加两列可选长讲解。导入按表头名称定位，允许调整列顺序或增加其他列，但全部必需表头必须唯一且存在。所有必需字段均不能留空；两个长讲解字段可以缺列或为空。

| 列 | 内容 |
| --- | --- |
| 罕度 | 0、1、2 或 3；越小越优先学习 |
| 组词 | 1–32 个汉字，简体教学词语；包括需单独学习的单字 |
| 拼音 | 带声调的普通话读音；轻声音节不标声调 |
| 简单例句 | 第一条完整中文例句，包含整个词语 |
| 例句拼音 | 第一条例句的声调拼音 |
| 例句英语翻译 | 第一条例句英文 |
| 词条ID | 1–92 位 ASCII 字母、数字或下划线，稳定且唯一 |
| 英文释义 | 用于答题的一个主义项，最多 300 字符 |
| 词性 | 该义项在例句中的词性，英文标注 |
| 第二例句 | 不同于第一句，包含完整词语并表达相同主义项 |
| 第二例句拼音 | 第二句的声调拼音 |
| 第二例句英语翻译 | 第二句英文 |
| 部件JSON | 有序 JSON 数组；每项有字符串 `hanzi`、`pinyin`、`gloss`；拼接 hanzi 必须还原词语 |
| 使用提示 | 中英用法说明；古语、地域用语、姓氏等注明适用语境 |
| 干扰词ID | 恰好三个不同词条 ID 的 JSON 字符串数组，不含本词；引用本 CSV 或已保存词条 |
| 来源说明 | 释义依据、例句与修改来源；该字段保留在 CSV 中，教学数据库不新增来源字段 |
| 本义解释 | 可选；中英双语字面义／基本义，不编造词源 |
| 引申义解释 | 可选；中英双语引申义，无独立延伸时留空 |

部件示例：`[{"hanzi":"学","pinyin":"xué","gloss":"learn"},{"hanzi":"习","pinyin":"xí","gloss":"practice"}]`。姓名、音译和不能可靠拆释的词可用整个词作为一个部件。部件讲解是记忆辅助，不能当作字源证明。

词语与部件拼音只使用拼音字母、声调字母、空白及音节分隔符；例句拼音还可使用常见中英文标点。支持 `ng`、`hng` 等鼻音，轻声不标调；不接受数字声调或把中文、纯标点当作拼音。两种 JSON 字段按上述字符串结构填写，键和值用双引号，正确转义控制字符；不接受注释、裸字符串、尾逗号或超过四层的嵌套。语义、词性和实际读音仍需作者核实，App 的字符格式检查不能代替语言审核。

原词 ID 采用 `wl_` 加原 CSV 数据行序号，例如原文件第 2 行对应 `wl_00001`。新增成语使用冻结选表中的 `cy_00001` 至 `cy_01000`；后续词频和文本变化不重新编号。CSV 增加可选列“本义解释”“引申义解释”，每列保存中文与英文讲解；缺列或空值兼容原 16 列格式。普通词没有独立引申义时留空该列，成语不把本义或典故放进选项。

## 限额与错误

- 文件最多 **32 MiB**，表头和每条记录最多 **64 列**，每条原始记录最多 **32 KiB**。
- 单次最多 **10,000 条**，追加后的整个词库也最多 **10,000 条**。
- 汉字 1–32 个、拼音最多 128 字符；例句汉字最多 1,000 字符，例句拼音与英文各最多 2,000 字符。
- 部件 JSON 最多 16,000 字符及 32 项；使用提示、来源、本义解释和引申义解释各最多 2,000 字符。
- 错误显示原文件物理行号和字段，最多显示前 100 项，同时保留错误总数。多行记录的内容错误定位到该记录起始行；语法错误定位到发生错误的物理行。整体文件、资源或库容量错误以 File 标识。
- 必需字段、ID、引用、选项区分和全部所需笔顺均校验通过，才能确认整批导入。任一错误阻止写入；不会先导入部分正确行。

## 追加与重复

手动导入仅追加。已有相同稳定 ID 的相同词、或相同「汉字＋规范化读音」的词跳过。规范化使用 NFC、忽略大小写与拼音空白，保留声调，因此 `bǒ` 与 `bì` 分别保留。相同 ID 对应不同词语或读音，整批拒绝。CSV 内稳定 ID 必须唯一；不同 ID 指向同词同读音时只保留第一条，并把后续引用映射到它。

升级安装中原有 20 个演示词保留，新装不再初始化演示词。相同词的 CSV 引用映射到实际旧词 ID，保留已有主义项 ID。受管预设词更新短义；手动重复导入仍保持已有短义。映射后的三个干扰项必须不同且不为本词，四个英文选项不能相同。手动重复导入不覆盖释义、学习进度、复习节点或写字记录。

预设 SHA-256 版本变化时，通过内部 `presetSourceId` 刷新受管理词的教学字段。旧安装仅在稳定 ID 与固定历史教学内容指纹一致时认领，不能仅凭同字同读音认领自定义内容。指纹排除罕度、排序和来源说明，涵盖实际释义、例句、拆字、提示及引用。手动导入不设置此归属字段。罕度仅同步到新增或已认领的预设词，未认领自定义词的教学内容和罕度均保持原值。

刷新保留实际 word/meaning ID、排序、书写关联与全部学习记录。拼音纠错必须列入受审核的旧读音→新读音登记；手动导入仍拒绝同 ID 不同身份。更新前检查未完成卡片原有四个 meaning ID 与更新后的短义；冲突时整批回滚，完成该旧卡后 Retry，不重判已提交答案。

## 加载进度与性能

首次加载、默认库重试和手动 CSV 读取／确认写入使用横向进度条、已处理／总词条数，以及阶段和 `Now loading …`。分母按 CSV 逻辑记录计数，引号内换行不另算一条；重复词也算已处理记录，计数不代表已提交的新增词数。启动使用构建生成的总量；外部 CSV 先快速计数，未知总量显示 `—`。

实际加载的总体进度连续递增：CSV 校验占 20%，笔顺占 65%，保存占 14%，提交阶段停留在 99%，事务成功后才显示 100%。CSV 预览单独使用校验 20%／笔顺 80%，100% 表示预览就绪，尚未写入数据库。进入确认写入或重试时开启新的进度；错误不伪装成成功。

进度只由加载协程汇总，最多每 100 ms 发布一次；首条、阶段切换和完成立即发布。只有进度组件订阅该 Flow，避免整页随字目刷新。笔顺索引与完整验证结果在进程内缓存，最多两个分包并发读取／解码，等待当前两个结束后再启动下一组。每包仍受 128 字／1 MiB 上限约束；数据库写入在事务所属协程中串行执行。首次完整验证与需要的笔顺写入合并，取消／失败保留事务回滚语义。

## 难度分级

罕度按学习期望划分，不设每档配额：0 必须掌握和记忆；1 需要了解和记住大致含义；2 需要见过、至少有印象；3 不要求掌握，不设任何期望。最终分布为 0=1,581、1=2,025、2=1,922、3=2,120。词频仅作辅助，结合具体义项、读音和使用场景判断；不是 HSK 等级。

CSV 保留 6,648 条旧词的物理顺序，再追加 1,000 条成语。通用现代义、常用成语优先；古语、旧义、方言、罕见读音及仅作专名的义项按具体学习价值降低期望。

[SUBTLEX-CH](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0010729) 固定词频表用于辅助选表，来源包 SHA-256 为 `cced9cb382914b93956a24fd06c10de709d351ff4501ac94c9ab136004421f07`。App 不分发完整语料，也不在运行时联网。

根目录 `wordlist.csv` 是最终校订的权威产物。作者记录、冻结选表和旧分级映射保存最后直接校订前的生产快照；运行旧生成器或 `--apply` 会覆盖最终校订，不能据此重建当前 CSV。 `tools/wordlist_difficulty.py --check` 和 `tools/complete_wordlist.py --check` 仍针对旧均分快照，不能作为最终 CSV 的核验命令；当前结构校验调用 `validate_csv_bytes(payload, verify_difficulty=False)`，并另核对四档学习期望、实际数量及 SHA-256。

## 笔顺与数据保存

CSV 不内嵌笔顺，也不从网络下载笔顺。导入词语的每一个字符位置必须能在随 App 分发的 `wordlist-strokes/index.json` 中找到真实轮廓和中线；重复字共享资源，但每个位置独立练习。若后续自制 CSV 含资源包之外的字，预览会报错，需要先补充并验证对应资源。

分包每包最多 128 字且不超过 1 MiB。优先使用固定版本 Make Me a Hanzi，缺字采用固定版本 AnimCJK 的简体中文资源；不使用日文字形代替，不生成假轮廓，不转换源坐标。资源包的来源、版本、SHA-256 和完整许可随 assets 保存，App 的 Data & licenses 提供查看入口。

最终 CSV 使用 6,323 个不同汉字，全部有资源。资源包共 6,324 字，保留全部 70 个已确认的 AnimCJK 补充字；其中琫单字资源仍保留，但原词琫珌因珌缺少笔顺而从 CSV 删除。

系统 URI 仅在应用层使用。选择后复制为 App 私有缓存中的随机临时快照，预览与确认读取同一个快照。取消、完成、读取失败时清理；App 再启动也清理遗留快照。代码不持久保存 URI，不新增存储权限、账号或联网权限。

Repository 的 `preview`、`commit`、`discard` 置于 domain 契约中。确认时在既有串行锁内重新校验，并在同一个 Room 事务中分批写入笔顺、词语、义项与逐字关联。失败或事务提交前的协程取消回滚整批。已完成提交后发生的取消不能撤销已提交事务。

Room 当前为 v6。历史迁移保持注册；5→6 给 `words` 增加 `literalExplanation`、`figurativeExplanation` 和内部 `presetSourceId`，均为 `TEXT NOT NULL DEFAULT ''`。保留原数据库文件名，不删除重建，不改进度与冻结计划表。默认库事务成功后才写入版本，失败或提交前的取消回滚整批。

## 内容来源与删除依据

原文件原样保存在 `wordlist.original.csv`，删除理由见 `wordlist-removals.csv`，25 个占位词的核实记录见 `wordlist-placeholder-audit.json`。没有因为整词未收录 CC-CEDICT 就删除可确认的古语、方言或组合词。

释义参考 [CC-CEDICT 官方资料](https://www.mdbg.net/chinese/dictionary?page=cc-cedict)（**CC BY-SA 4.0**）与 [mapull/chinese-dictionary](https://github.com/mapull/chinese-dictionary) 固定提交 `e804ada333b68afddfdccbe8dcc938a72da157a7`。后者声明 MIT，同时注明部分收集资料的原始来源无法确定；它作为具名参考使用。上游完整 MIT 许可随 App 保存并在 Data & licenses 展示。

新增成语按整词语境频率选择，再与英文义项及真实笔顺资源交叉筛选，并非把网络列表截取前 1,000 行。其 2,000 个现代语境例句为新撰写内容。旧词按保留读音补充中文释义、完整讲解和拆分；有效原句保留，问题条目单独校订。机器辅助的英译、中文译稿和句子拼音在每词来源及审计中标明，不能视为全部词条经过人工语言审核。详情见 [本次内容与验证记录](WORDLIST_REFINEMENT.md)。

成语题使用三项语义不同的成语作为干扰项，四项均以 `Describes …` 显示现代义，避免唯一的句式或前缀泄露答案。普通词仍沿用既有干扰规则。

[Make Me a Hanzi](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92) 固定版本为 `bddc96d41bef78427ed0e034e9f7e31d71fd1b92`；[AnimCJK](https://github.com/parsimonhi/animCJK/tree/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6) 固定版本为 `ec5e17cca76c87587790bcbce5ea0b4d4fb753d6`。两者字形数据的 Arphic Public License 与独立 App 代码分别归属；未引入 AnimCJK 的 LGPL 动画代码。

最终 CSV 的静态校验结果见 `docs/wordlist-validation.json`，其中 `preFinalCsvSnapshot` 仅保留此前生产与验证证据。资源一致性可用 `python tools/build_wordlist_strokes.py --check` 只读核对。`CSV_STATIC_REVIEW.md` 保留早期 0–2 分级与旧数据库版本的历史记录。最终校订后未重打包或执行设备操作；读音升级登记仅为这两条明确旧读音到新读音开放，不改变手动导入的身份检查。
